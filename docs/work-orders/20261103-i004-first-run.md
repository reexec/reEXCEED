# Work order: lifting the North America build and the first boot (issue #4)

Design: [20261103-i004](../design/20261103-i004-first-run.md)

1. Generate `gen/exceed_us/` with `python scripts\recomp\regenerate.py`; record the function count, unresolved stubs, unimplemented instructions and identified XDK functions and variables.
2. Build Win32 x86 Debug and run CTest.
3. Run `REXBOX_DISPLAY=hidden REXBOX_AUDIO=none REXBOX_WATCHDOG=60 reexceed.exe roms` and see where it stops.
4. Pass each stop as design §2's table says; rexbox changes go through rexbox issues.
5. Put confirmed facts into `docs/analysis/exceed-xbe-overview.md` and `docs/XBE_DESIGN.*`.
6. Update the work log and commit each session (`(#4)`).
