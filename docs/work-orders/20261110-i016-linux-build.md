# 작업 지시서: Linux 실기에서 생성, x64·x86 빌드, 실행 (issue #16)

* 관련 이슈: #16
* 설계 문서: [`docs/design/20261110-i016-linux-build.md`](../design/20261110-i016-linux-build.md)
* 역할: Claude가 총괄·설계·리뷰, Antigravity가 구현(명령 실행, 코드 수정). 각 단계의 결과는 Claude가 확인한 뒤 다음 단계로 간다.

## 작업 단계

1. **게임 파일**(사용자): extract-xiso로 `roms/Pump It Up - Exceed (USA).xiso.iso`를 `roms/`에 푼다. `roms/DEFAULT.XBE`의 MD5가 `575f861eb700e86a82c0ad530dc4a310`인지 확인한다.
2. **생성**: `cmake --preset linux-x64-release`, `cmake --build --preset linux-x64-release --target rexbox_xdk_symbols`, `python3 scripts/recomp/regenerate.py`. 소요 시간과 경고를 기록한다.
3. **x64 빌드**: `scripts/build_linux.sh x64 release`. 오류와 새 경고, CTest 결과(7개)를 기록한다. 깨지면 고치기 전에 원인과 수정안을 Claude에게 보고한다.
4. **x86 빌드**: `scripts/build_linux.sh x86 release`. 3과 같다.
5. **숨김 실행**: 실행 디렉터리 `~/exceedrun`에서 `REXBOX_DISPLAY=hidden REXBOX_AUDIO=none REXBOX_WATCHDOG=100 REXBOX_D3D8_PROFILE=600`으로 x64(그다음 x86)를 약 120초 돌리고 로그를 남긴다.
6. **창 실행**: 사용자가 표시, 소리, 입력을 확인한다.
7. **저장소 정리**: `git update-index --chmod=+x scripts/build_linux.sh`, Linux 가이드와 README 플랫폼 표 갱신.
8. **작업 로그**: `docs/work-logs/20261110-i016-linux-build.md`.

# Work Order: Generation, x64 and x86 Builds and a Run on a Linux Machine (issue #16)

* Related issue: #16
* Design document: [`docs/design/20261110-i016-linux-build.md`](../design/20261110-i016-linux-build.md)
* Roles: Claude leads, designs and reviews; Antigravity implements (runs commands, edits code). Claude checks each step's result before the next one starts.

## Steps

1. **Game files** (the user): extract `roms/Pump It Up - Exceed (USA).xiso.iso` with extract-xiso into `roms/`. Check that the MD5 of `roms/DEFAULT.XBE` is `575f861eb700e86a82c0ad530dc4a310`.
2. **Generation**: `cmake --preset linux-x64-release`, `cmake --build --preset linux-x64-release --target rexbox_xdk_symbols`, `python3 scripts/recomp/regenerate.py`; record the time taken and any warnings.
3. **x64 build**: `scripts/build_linux.sh x64 release`; record errors, new warnings and the CTest result (seven tests). When something breaks, report the cause and a proposed fix to Claude before fixing it.
4. **x86 build**: `scripts/build_linux.sh x86 release`, as in step 3.
5. **Hidden run**: from `~/exceedrun`, run x64 (then x86) for about 120 seconds with `REXBOX_DISPLAY=hidden REXBOX_AUDIO=none REXBOX_WATCHDOG=100 REXBOX_D3D8_PROFILE=600`, keeping the log.
6. **Windowed run**: the user checks picture, sound and input.
7. **Repository**: `git update-index --chmod=+x scripts/build_linux.sh`; update the Linux guide and the README platform table.
8. **Work log**: `docs/work-logs/20261110-i016-linux-build.md`.
