## reEXCEED v0.0.11 (English)

The changes since **v0.0.10**. **Screen shaders can be chosen**, as in reDMP1. Screen shader in the Graphics tab of the `F1` Settings window offers `crt`, `scanline`, `fsr`, `scalefx`, `anime4k` or a user file in `shaders/`, with its parameters.

* [#20](https://github.com/reexec/reEXCEED/issues/20) (`91d05d9`, `2b3a468`, `865175c`):
  * the Graphics tab's Screen shader section (combo, Reload, error, sliders);
  * `[Graphics] PostShader`, `--post-shader <id>` and `REEXCEED_POST_SHADER`. The command line wins over the environment, which wins over the ini, and the first two are not written to the ini.
  * the `shaders/` directory and `reexceed_settings_probe`.
* [#9](https://github.com/reexec/reEXCEED/issues/9): v0.0.10's music loader fix was confirmed by the user's reproduction runs, and the issue is closed.

Submodules:
* `third_party/rexbox` at rexbox `v0.0.33` (`af36e2f`, was `v0.0.32`): screen shaders at presentation (rexbox #91).
* `third_party/xboxrecomp` unchanged at upstream `v0.18.0` (`37b61d5`).

Known limits: the loading-screen thread's GL work has no effect (rexbox #65).

Verified:
* Win32 x86 Release and Debug (generated code): 0 errors, 0 warnings, CTest 9/9.
* A run: `crt` applies upright with the overlay unshaded at 60 fps, and `none` looks as before; checked by the user.

The source archives do not contain the submodules. To build, clone with `git clone --recurse-submodules https://github.com/reexec/reEXCEED.git`.
