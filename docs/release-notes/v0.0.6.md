## reEXCEED v0.0.6 (English)

The changes since **v0.0.5** (part of issue #9). **Locked songs on the song select show grey pictures with a lock, as in xemu.**

Issue #9 (in progress): the locked songs' pictures and the centre preview, fixed by rexbox #73 (a pixel shader the title's library created) (`b383001`).

Submodules:
- `third_party/rexbox` at rexbox `v0.0.25` (`56bc8a5`, was `v0.0.24`).
- `third_party/xboxrecomp` unchanged at upstream `v0.16.0` (`f0f8a46`).

Known limits:
- Music has been reported missing at times, but it has not been reproduced (#9).
- The loading-screen thread's GL work has no effect (rexbox #65).

Verified:
- Win32 x86 Debug and Release (generated code): 0 errors and 0 warnings, CTest 7/7.
- `reexceed roms`: the locked song's (FOREVER LOVE) tile picture and preview on the song select come out grey as in xemu (the user's check).

The source archives do not contain the submodules. To build, clone with `git clone --recurse-submodules https://github.com/reexec/reEXCEED.git`.
