| issue | 내용 | 커밋 |
|---|---|---|
| [#6](https://github.com/reexec/reEXCEED/issues/6) | ESRB 공지와 로고: lifter가 8비트 단일 피연산자 `imul`을 32비트로 옮겨 PNG 높이(EDX)가 0이 되던 것을 lift 단계에서 우회 | `00d6cec` |

* **재컴파일**: `scripts/recomp/lifter_patches.py`가 lift 단계에서 8·16비트 단일 피연산자 `mul`/`imul`을 제 폭으로 옮긴다. 같은 수정이 upstream PR sp00nznet/xboxrecomp#277에 있고, upstream 릴리스가 나오면 지운다. 자체 검사는 `scripts/recomp/test_lifter_patches.py`다. **생성 코드를 다시 만들어야 한다**(`python scripts/recomp/regenerate.py`).
* **분석**: `docs/analysis/exceed-xbe-overview.md`에 부팅 BGA와 libpng(§13).

## reEXCEED v0.0.4 (English)

The changes since **v0.0.3** (issues #6, #7). **The ESRB notice and the company logos show at boot, and START at the title leads into SELECT MODE, the song select and the difficulty select.**

Issues:
- #6, the ESRB notice and the logos (`00d6cec`). The lifter turned an 8-bit one-operand `imul` into a 32-bit product, which zeroed the PNG height kept in EDX; the lift step now works around it.
- #7, the stop after START at the title (`7cae1c8`), fixed by rexbox #62–#64: the window thread, the critical-section hand-off and a bound on the GL error drain.

Changes:
- **Recompilation.** `scripts/recomp/lifter_patches.py` lifts 8- and 16-bit one-operand `mul`/`imul` at their own width during the lift step. The same fix is upstream PR sp00nznet/xboxrecomp#277, and the workaround goes once an upstream release carries it. The self-check is `scripts/recomp/test_lifter_patches.py`. **The generated code must be regenerated** (`python scripts/recomp/regenerate.py`).
- **Analysis.** `docs/analysis/exceed-xbe-overview.md` gains the boot BGA and libpng (§13).

Submodules:
- `third_party/rexbox` at rexbox `v0.0.23` (`25587f7`, was `v0.0.22`).
- `third_party/xboxrecomp` unchanged at upstream `v0.16.0` (`f0f8a46`).

Known limits:
- The loading-screen thread's GL work has no effect (rexbox #65), so the screen does not change while loading.
- The rest is as in v0.0.3: sound not yet checked, uninterpreted push-buffer methods, and the indirect call at `000C67A6`.

Verified:
- Win32 x86 Debug and Release (generated code): 0 errors and 0 warnings, CTest 7/7.
- The lifter patches pass their self-check (11/11 untouched forms, 5,110/5,110 narrow-form vectors), and upstream's `pytest tools/` gives the same results with and without them.
- `reexceed roms` (window shown, audio, keyboard) shows the ESRB, AM, Andamiro and Mastiff logos, then goes from START at the title → SELECT MODE → song select → difficulty select with no stop in 120 s.

The source archives do not contain the submodules. To build, clone with `git clone --recurse-submodules https://github.com/reexec/reEXCEED.git`.
