## reEXCEED v0.0.10 (English)

The changes since **v0.0.9**. **xboxrecomp moves to upstream v0.18.0, and the cause of the song music that sometimes did not play (a race with the music loader thread) is fixed.** With rexbox v0.0.32, F10 in the window prints the guest thread report.

* [#18](https://github.com/reexec/reEXCEED/issues/18) (`42231df`):
  * xboxrecomp v0.16.0 → v0.18.0: unresolved call targets 3 → 0, unimplemented instructions 74 → 10.
  * #6's temporary lifter patch is removed (upstream #277); the patch mechanism stays.
  * `sub_00038D60` follows the lifted code's call-boundary convention (EBP and flags publishing, upstream #280 and #311). `CODING_STYLE.md` records the convention, and `reexceed_decomp_check` compares `g_eflags` too.
* [#9](https://github.com/reexec/reEXCEED/issues/9), reopened (`05864dd`, `c23c2e5`):
  * The cause: the music start functions write "loading" `[0x843550] = 1` **after** creating the loader thread. On the host a loader that finished first left the flag at 1, and music and sound effects stopped.
  * The fix is an ordering adapter in front of the loader `sub_0007DFD0` (`decomp/music_loader_order.c`, implemented by Antigravity).

Submodules:
* `third_party/rexbox` at rexbox `v0.0.32` (`67eaabc`, was `v0.0.26`). v0.0.27-v0.0.31 are GL and D3D8 performance and diagnostics plus a guest-wait C API, with nothing for consumers to do; v0.0.32 is the F10 thread report (rexbox #89).
* `third_party/xboxrecomp` at upstream `v0.18.0` (`37b61d5`, was `v0.16.0`).

For consumers: regenerate the code with `python scripts/recomp/regenerate.py` (xboxrecomp changed, and `sub_0007DFD0_gen` is new).

Known limits:
* The #9 fix is not yet confirmed by user reproduction runs (songs played several times without diagnostic options); #9 is closed once it is.
* The loading-screen thread's GL work has no effect (rexbox #65).

Verified:
* Win32 x86 Release and Debug (generated code): 0 errors, 0 warnings, CTest 7/7, `reexceed_decomp_check` with 3 cases, 0 differences and four functional checks.
* A run: reaches the title screen, the music loader opens the title music through the adapter, and F10 prints the thread report.

The source archives do not contain the submodules. To build, clone with `git clone --recurse-submodules https://github.com/reexec/reEXCEED.git`.
