## reEXCEED v0.0.8 (English)

The changes since **v0.0.7**. **The settings window gains a temporary unlock of everything, autoplay and a full-size picture.**

* [#13](https://github.com/reexec/reEXCEED/issues/13) (`32866d2`): all songs, charts, speed/note modifiers and sub-modes unlocked in memory only, never changing the save file (`[Game] UnlockAll`), and the game's built-in autoplay (`[Game] Autoplay`), in the `F1` Settings window's Game tab.
* [#14](https://github.com/reexec/reEXCEED/issues/14) (`32866d2`): a full-size picture that turns off the game's TV-overscan shrink of the whole picture to 83% (`[Graphics] FullSizePicture`, on by default), in the Graphics tab.

Submodules unchanged: `third_party/rexbox` at rexbox `v0.0.26` (`f4878af`), `third_party/xboxrecomp` at upstream `v0.16.0` (`f0f8a46`).

Known limits: changing the full-size picture while running shows from the next screen setup (scene change); the loading-screen thread's GL work has no effect (rexbox #65).

Verified: Win32 x86 Debug and Release (generated code) with 0 errors and 0 warnings, CTest 7/7 (`reexceed_decomp_check`: 3 cases, 0 differences, plus the unlock, autoplay and full-size picture checks); a run at intro movie frame 1500 fills 1280x960 with the setting on and shows 1066x800 with a black border with it off.

The source archives do not contain the submodules. To build, clone with `git clone --recurse-submodules https://github.com/reexec/reEXCEED.git`.
