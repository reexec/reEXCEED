## reEXCEED v0.0.3

이전 릴리스 **v0.0.2** 이후의 변경입니다(issue #4). **북미판이 재컴파일 코드로 부팅해 시작 동영상과 타이틀 화면("PRESS START BUTTON")까지 그립니다.** 입력으로 메뉴에 들어가는 것과 소리 확인은 다음 작업입니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#4](https://github.com/reexec/reEXCEED/issues/4) | 북미판의 첫 실행: lift, XAPI·XACT 어댑터, rexbox #49~#58·#60 위에서 타이틀 화면까지 | `2dce873`, `ac3d089`, `ea2b513`, `c0fbfd6`, `d18dd2c`, `5935bf4`, `6793a6c`, `45ed313` |

### 바뀐 것

* **재컴파일**: 북미판 lift(`scripts/recomp/regenerate.py`, 생성 코드는 로컬에만). `hle_libraries.json`에 XNET 2개와 lift로 남기는 XDK 함수들, `xdk_symbols_extra.json`에 `D3DDevice_ApplyStateBlock`(`0x00174BED`). 스크립트들이 XBE를 대소문자 없이 찾는다.
* **타이틀**: 프로파일의 XDK 내부 주소 `D3D_g_Device`(`0x001835E0`), `D3D_InitializeDeviceState`(`0x0017A1E0`), `D3DDevice__m_Transform_OFFSET`(`0xC60`). 디컴파일 함수 2개: XAPI 코드 선택(`sub_00087E12`, 아무것도 하지 않음), XACT 샘플 시계(`sub_0016F12A`, 호스트 훅 `reexceed_host_apu_sample_count`로 rexbox의 APU 샘플 카운터를 읽음).
* **앱**: `KernelConfig::image_file_name`에 불러온 XBE 이름. 로드에서 멈추는 경로는 `std::_Exit(0)`.
* **분석**: `docs/analysis/exceed-xbe-overview.md`에 부팅 경로, 커널 import, D3D8 렌더 경로(XDK 5849의 렌더 상태 배치, 디바이스 변환 배열).

### submodule

* `third_party/rexbox`: rexbox `v0.0.22`(`b77dab0`). 이전 `v0.0.21`.
* `third_party/xboxrecomp`: upstream `v0.16.0`(`f0f8a46`), 그대로.

### 알려진 한계

* 입력(START)으로 메뉴에 들어가는 것, 소리와 스트림 패킷 완료는 확인하지 않았다.
* 디바이스 푸시 버퍼의 NV2A 메서드 12개를 해석하지 않는다(보고만 한다).
* Debug 빌드는 패드가 연결될 때 SDL 단언으로 끝난다(종료 코드 3, rexbox 후속 issue). Release는 문제없다.
* `000C67A6`의 간접 호출 대상 `8298BC05`가 코드 밖이다(보고만 한다).

## reEXCEED v0.0.3 (English)

The changes since **v0.0.2** (issue #4). **The North America build boots through recompiled code and draws its opening movie and the title screen ("PRESS START BUTTON").** Entering the menus through input and checking sound come next.

Issue: #4, the first run of the North America build: the lift, the XAPI and XACT adapters, and up to the title screen on rexbox #49–#58 and #60 (`2dce873`, `ac3d089`, `ea2b513`, `c0fbfd6`, `d18dd2c`, `5935bf4`, `6793a6c`, `45ed313`).

Changes: the North America lift (`scripts/recomp/regenerate.py`; the generated code stays local), with two XNET functions and the XDK functions kept lifted in `hle_libraries.json`, `D3DDevice_ApplyStateBlock` (`0x00174BED`) in `xdk_symbols_extra.json`, and the scripts finding the XBE ignoring case; the profile's XDK internals `D3D_g_Device` (`0x001835E0`), `D3D_InitializeDeviceState` (`0x0017A1E0`) and `D3DDevice__m_Transform_OFFSET` (`0xC60`); two decompiled functions, the XAPI code selector (`sub_00087E12`, a no-op) and the XACT sample clock (`sub_0016F12A`, reading rexbox's APU sample counter through the host hook `reexceed_host_apu_sample_count`); the app passes the loaded XBE's name as `KernelConfig::image_file_name` and leaves the load-stop paths with `std::_Exit(0)`; the analysis document gains the boot path, the kernel imports and the D3D8 render path (XDK 5849's render-state layout and the device transform array).

Submodules: `third_party/rexbox` at rexbox `v0.0.22` (`b77dab0`, was `v0.0.21`); `third_party/xboxrecomp` unchanged at upstream `v0.16.0` (`f0f8a46`).

Known limits: entering the menus with START, sound and stream packet completion are not checked; twelve NV2A methods in the device push buffer are only reported; Debug builds end on an SDL assertion when the pad arrives (exit code 3, a rexbox follow-up), Release builds are fine; the indirect call at `000C67A6` targets `8298BC05`, outside the code (reported only).

Verified: Win32 x86 Debug and Release (generated code) with 0 errors and 0 warnings and rexbox's probes recomp 8, kernel 103, dsound 73 and d3d8 234 checks; `reexceed roms` (Release, hidden, no audio) runs past 120 s at 60 fps, with the opening movie at frame 1500 and the title screen at frame 3600.

The source archives do not contain the submodules. To build, clone with `git clone --recurse-submodules https://github.com/reexec/reEXCEED.git`.
