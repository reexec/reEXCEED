## reEXCEED v0.0.7 (English)

The changes since **v0.0.6** (closing issue #9). **rexbox's DSOUND diagnostics (stream statistics, signal levels, an output WAV dump) are now available.** There is no code change.

Issue #9 is closed (`8a8a2af`, `b383001`). The in-game BGA, the STAGE BREAK and GAME OVER videos and the locked-song pictures were fixed in v0.0.5 and v0.0.6. The music did not reproduce; if it does, the issue is reopened.

Submodules:
- `third_party/rexbox` at rexbox `v0.0.26` (`f4878af`, was `v0.0.25`).
- `third_party/xboxrecomp` unchanged at upstream `v0.16.0` (`f0f8a46`).

If the music problem comes back, run the commands above, keep playing a song without music for 20–30 s, quit, and attach the record and the WAV to #9.

Known limits: the loading-screen thread's GL work has no effect (rexbox #65).

Verified: Win32 x86 Debug and Release (generated code) with 0 errors and 0 warnings, CTest 7/7, `rexbox_dsound_probe` 84 checks.

The source archives do not contain the submodules. To build, clone with `git clone --recurse-submodules https://github.com/reexec/reEXCEED.git`.
