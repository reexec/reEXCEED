## reEXCEED v0.0.2

첫 릴리스입니다(issue #1, #2). **Pump It Up: Exceed(북미판, XDK 5849) 포팅 프로젝트의 준비 단계입니다.** reCT3와 reJSRF의 규칙, 앱, 파이프라인을 공유 런타임 rexbox 위에 갖추었고, 앱은 북미판 `default.xbe`를 식별하고 게스트 메모리에 배치한 뒤 멈춥니다. 재컴파일 코드 생성과 부팅은 다음 작업입니다.

### 바뀐 것

* **앱**(`reexceed`): 설정 파일(`reexceed.ini`)과 Tab 메뉴(Graphics, Input, Stats, Info), 통계 창. reJSRF에서 Info 탭의 rexbox 버전·커밋, 절반 높이의 Stats 그래프, Debug 빌드의 미해결 스텁 보고(`RECOMP_STUB_LOG=1`)를 더했다. 게임 디렉터리의 `default.xbe`를 대소문자 없이 찾는다(디스크의 `DEFAULT.XBE`).
* **타이틀**: 북미판 등록(MD5 `575f861e…`, title id `41440002`, 인증서 시각 `42F8EC5C`). XDK 내부 주소, 시드, 추가 심볼은 아직 없다.
* **파이프라인**: `scripts/recomp/`(lifter, regenerate, register, HLE pop 확인, 포인터 대상), `reexceed_decomp_check` 틀.
* **분석**: `docs/analysis/exceed-xbe-overview.md`. 섹션 19개, XDK 5849 라이브러리 14개(WMADEC, XMV, XACTENG, XONLINE 포함), 커널 import 146개 중 42개가 rexbox에 없음, 디스크 구성.

## reEXCEED v0.0.2 (English)

The first release (issues #1, #2). **The preparation stage of the Pump It Up: Exceed (North America, XDK 5849) port.** reCT3's and reJSRF's rules, app and pipeline are in place on the shared rexbox runtime; the app identifies the North America `default.xbe`, places it in guest memory and stops. Generating the recompiled code and booting come next.

Resolved: #1, the project bootstrap (reCT3's tree with reJSRF's improvements, rexbox v0.0.21, upstream xboxrecomp v0.16.0, the North America build registered, documents; `45121b4`); #2, GitHub Actions (build and CTest on `main`, tag verification, releases from a tag and its release note; `c1da2ac`).

Changes: the app (`reexceed`) has the settings file (`reexceed.ini`), the Tab menu (Graphics, Input, Stats, Info) and the stats window, plus from reJSRF the Info tab's rexbox version and commit, half-height Stats graphs and the unresolved-stub report in Debug builds (`RECOMP_STUB_LOG=1`); it finds `default.xbe` ignoring case (the disc's `DEFAULT.XBE`). The North America build is registered (MD5 `575f861e…`, title id `41440002`, certificate time `42F8EC5C`); no XDK internals, seeds or extra symbols yet. The pipeline (`scripts/recomp/`) and the `reexceed_decomp_check` framework are in. `docs/analysis/exceed-xbe-overview.md` records 19 sections, 14 XDK 5849 libraries (WMADEC, XMV, XACTENG and XONLINE among them), 146 kernel imports of which 42 have no rexbox export, and the disc layout.

Submodules: `third_party/rexbox` at rexbox `v0.0.21` (`bc21519`); `third_party/xboxrecomp` at upstream `v0.16.0` (`f0f8a46`).

Known limits: without recompiled code the game does not run; a segfault at exit on Linux after the load stage is avoided with `std::_Exit`, with the cause (teardown order) inferred and a rexbox issue candidate.

Verified: Win32 x86 Debug and Release with 0 warnings and CTest 6/6 (rexbox probes 8 / 94 / 73 / 223 checks, two app smoke tests); Linux x64 and x86 Release on WSL2 Ubuntu 24.04 with CTest 6/6; `reexceed roms` on all three identifies the North America build, places 19 sections, binds 104 of 146 kernel imports and exits 0 after load.

Source archives hold no submodules; build from `git clone --recurse-submodules https://github.com/reexec/reEXCEED.git`.
