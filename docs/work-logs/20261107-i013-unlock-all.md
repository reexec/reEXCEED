# Work Log: Temporary Unlock-All and Autoplay Settings (issue #13)

Design: [20261107-i013](../design/20261107-i013-unlock-all.md) · Work order: [20261107-i013](../work-orders/20261107-i013-unlock-all.md)

## Work Done

1. **Original XBE Analysis & Knowledge Base**:
   - Confirmed and documented the dirty-check structure of the save buffer (`0x0084865C`, `0x5028` bytes: `save_ptr` vs `save_ptr + 0x2800` via `repe cmpsd` before invoking `sub_00072F10`).
   - Identified all four unlock areas:
     - Songs & charts: `save_ptr + 0x1373` (active lock) & `0x1773` (default lock), copied by `sub_000278A0` into `.data` table `0x001C5D88`.
     - Speed & note modifiers: 7 category flags (`+0x1F75..+0x1F7D`) and 17 sub-item flags (`+0x1F93..+0x1FBD`).
     - Sub-modes: `sub_00038D60` populating 11 sub-modes via `sub_00038CE0` indirect jump table.
   - Identified built-in autoplay:
     - `"PLAY"` scene pointer (`MEM32(0x00825114)`), `play_ptr + 0x39D` flag, `sub_00017530` frame loop driving bot `sub_0001E630`.
   - Updated `docs/analysis/exceed-xbe-overview.md` §14, `docs/XBE_DESIGN.ko.md` §5, `docs/XBE_DESIGN.en.md` §5, and `ARCHITECTURE.md`.

2. **Host Bridge & Decompiled Functions**:
   - `include/reexceed/exceed_host.h`, `src/game/exceed/exceed_host.c`: Defined host state flags and APIs.
   - `src/game/exceed/decomp/unlock_all.c`:
     - `sub_000278A0`: Backs up original modifier options and applies memory unlock upon Song Select entry.
     - `sub_00033340`: Restores options and lock tables on Song Select teardown/exit (`vtable[3]`), cleanly preventing dirty save writes to disk.
     - `sub_00038D60`: Displays all 11 sub-modes on Mode Select.
     - `reexceed_decomp_sync_unlock_all`, `reexceed_decomp_sync_autoplay`: Live sync helpers during active scenes.
   - Lifter pipeline rerun: emitted `sub_000278A0_gen`, `sub_00033340_gen`, `sub_00038D60_gen`.

3. **App Settings & ImGui UI**:
   - `src/app/settings.h`, `src/app/settings.cpp`: `[Game]` section `UnlockAll`, `Autoplay` INI persistence.
   - `src/app/settings_ui.h`, `src/app/settings_ui.cpp`: Added `Game` section and `Unlock all songs, modes, and modifiers (temporary)`, `Autoplay` checkboxes to `F1` Settings window.
   - `src/app/main.cpp`: Injects INI values at startup and dispatches per-frame live sync.

4. **MSVC Debug Build Stabilization**:
   - `src/game/exceed/CMakeLists.txt`: Configured `/Z7` (embedded object debug info) in Debug for `reexceed_recomp` to resolve `fatal error C1902: Program database manager mismatch` caused by `/Zi` + `/MP` and `mspdbsrv.exe` PDB contention on 23 massive generated C files.
